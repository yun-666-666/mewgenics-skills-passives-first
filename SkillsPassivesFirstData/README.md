# Skills & Passives First - 3 Rerolls data MOD

This Mewtator data MOD adds the game's native `AddLevelUpRerolls 3` **innate
passive** to every vanilla player class, including `Colorless`. Every ordinary
player cat therefore receives three rerolls whenever its level-up choices are
shown.

It is deliberately separate from the DLL: the DLL changes the level-10+ first
screen, while this data MOD supplies reroll charges through the same class
mechanism used by the vanilla "99 rerolls" example MOD. It does not alter
`resources.gpak`.

Enable this folder in Mewtator together with the `SkillsPassivesFirst.dll`
chainloader MOD. Do not enable Solo Leveling at the same time.
